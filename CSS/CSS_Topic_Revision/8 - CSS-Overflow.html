CSS Overflow Live Playground

1. Overflow: Visible (Ziddi - Deewar tod kar bahar)

Bhai ye text dabe ke bahar nikal jayega kyunki humne isme zaroorat se zyada content bhar diya hai aur default behavior visible hota hai. Dekho kaise ye niche bhaag raha hai!

2. Overflow: Hidden (Mr. India - Baahar ka saaman gayab)

Bhai ye text bhi dabe se bahar jana chahta tha par humne ispar hidden ka brahmastra laga diya. Ab browser iski deewar ke bahar ke saare extra aksharon ko kaat kar poora chupa dega.

3. Overflow: Scroll (Zabardasti Scrollbar)

Is dabe mein browser vertical aur horizontal dono scrollbars laga dega. Chahe saaman chota ho ya bada, scrollbar hamesha gande dikhte rahenge.

4. Overflow: Auto (The Smart Intelligent Player)

Yeh sabse best hai! Agar text chota hoga toh koi scrollbar nahi dikhayega. Par jaise hi text bada hua aur deewar todne laga, isne automatic andar ek badhiya scrollbar prakat kar diya.
