## 🎓 What I've Mastered So Far

### ✅ HTML5 Fundamentals
- Document structure, semantic markup (header, nav, main, footer)
- Forms, input types, and validation basics
- Media elements (images, audio, video)
- SEO fundamentals and Core Web Vitals
- Accessibility best practices

### ⏳ CSS3 (In Progress)
- Selectors, specificity, and cascade
- Box model — margin, padding, border
- Typography, colors, and sizing units (px, rem, em, %, vh/vw)
- Position, display, and overflow properties
- CSS Variables and theming
- Media Queries — responsive design across breakpoints
- **Flexbox** — flexible, modern layouts
- **CSS Grid** — grid-based layouts, responsive grids with media queries
- Transforms, Transitions, and Keyframe Animations
- Object-fit / Object-cover for image handling *(current topic)*

### 📋 Coming Next
- **JavaScript** — variables, functions, loops, DOM manipulation, events, callbacks, promises, async/await, fetch API, OOP, error handling
- **Tailwind CSS** — utility-first styling
- **React.js** — components, JSX, hooks (useState, useEffect, useRef, useContext, useMemo, useCallback), routing, Redux
- **Node.js & Express.js** — server-side JavaScript, REST APIs, middleware
- **MongoDB & Mongoose** — database design, CRUD operations
- **Next.js** — server components, API routes, SSR/SSG/ISR, authentication, deployment

## 💻 How to Use This Repository

1. **Start with HTML** — Follow folders sequentially (01 → 02 → 03...)
2. **Move to CSS** — Apply styling concepts to HTML projects
3. **Practice relentlessly** — Modify examples, build variations, break things and fix them
4. **Build real projects** — Apply concepts in actual mini-projects, not just isolated exercises

### Do's ✅
- Read and understand code before copying
- Experiment with different property values
- Use browser DevTools to inspect and debug
- Test layouts on different screen sizes
- Understand the *why*, not just the *how*

### Don'ts ❌
- Copy-paste without understanding
- Skip practice exercises
- Ignore error messages
- Rush through topics just to "finish" them
- Test on only one device/screen size
