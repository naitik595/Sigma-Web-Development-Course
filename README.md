## 🎓 What I've Mastered So Far

### ✅ HTML5 Fundamentals
- Document structure, semantic markup (header, nav, main, footer)
- Forms, input types, and validation basics
- Media elements, SEO fundamentals, accessibility basics

### ✅ CSS3
- Selectors, specificity, box model, typography, and color systems
- Sizing units (px, rem, em, %, vh/vw) and responsive design
- Position, display, and overflow properties
- CSS Variables and theming
- Media Queries for responsive breakpoints
- **Flexbox** and **CSS Grid** — modern, responsive layouts
- Transforms, transitions, and keyframe animations
- Object-fit / object-cover for image handling

### 📋 Coming Next
- **JavaScript** — variables, functions, DOM manipulation, events, async/await, fetch API, OOP
- **Tailwind CSS**, **React.js**, **Node.js / Express.js / MongoDB**, **Next.js**

## 💻 How I Use This Repository

1. Follow each topic folder sequentially, understand the concept before moving on
2. Complete exercises without checking solutions first
3. Apply concepts in real mini-projects, not just isolated snippets
4. Use browser DevTools to inspect, debug, and experiment

### Do's ✅
- Read and understand code before writing it
- Experiment with different property values
- Test layouts across screen sizes
- Understand the *why*, not just the *how*

### Don'ts ❌
- Copy-paste without understanding
- Skip practice exercises
- Rush through topics just to finish them
