CSS Selector Practice

What is Element Selector?

An element selector is a CSS rule that targets and styles HTML elements directly by their tag names, such as p, h1, or div. It applies the specified styles to every instance of that tag across the entire webpage automatically.

What is Class Selector?

A class selector is a CSS rule that targets and styles HTML elements using a custom name preceded by a period, like .highlight. It allows you to apply the exact same styling to multiple chosen elements across your webpage, regardless of their tag type.
